A line chart for business time series that answers the question the meeting is about: are we on plan? Actual against plan and prior year with the gap shaded green or red, the plan carried on past the last actual month, the last value at the end of every line, and an empty month drawn as a gap, never as a zero. Pro adds the context around the numbers: events and annotations on the timeline, the variance in the end label, small multiples, “Show values as” and six collection styles.

Video on YouTube: https://www.youtube.com/watch?v=R7EQ3PDNhMs

Quick Start

  1. Add Line Chart by TCViz to the page. With no fields it shows a start screen with these steps.
  2. Drag a date to Axis — the date column itself, for a real time axis.
  3. Drag a measure to Values — Sales. Add a Legend (Region) for one line per value.
  4. Drag your plan measure to Plan, and turn on Plan, prior year and forecast → Gap shading.
  5. The setup guide in the corner lists the optional fields and lets you try each Pro feature on your data.

How to read it

Read the actual line against the plan: the shaded area is the gap, split where the lines cross. Past the “Actual | Plan” mark only the plan (or forecast) continues. A break in a line is a period without data, not a zero.

Use cases

Monthly sales against plan

Axis = Month, Values = Sales, Plan = Sales plan. Turn on Gap shading: months above plan in green, below in red. The plan carries on after the last actual month, so the rest of the year is on the same chart.

This year against last year

Prior year = a time-intelligence measure such as CALCULATE([Sales], SAMEPERIODLASTYEAR('Date'[Date])). With Pro, the end label can show the variance: “+4.2% vs PY”.

Regions with a margin on a second axis

Values = Sales, Legend = Region, Secondary values = Margin %. Each region has its end label with its last value, and the margin reads on the right-hand axis.

Daily data with a trend

A daily date on Axis, a Trend line (moving average of 7 periods) and Peaks & lows. Ctrl + wheel zooms into a month; the Y axis fits the zoomed range.

Campaigns, price changes and incidents (Pro)

An Events table with Date and Event, related to the calendar: each event is a vertical line with its text, so the reason for a jump is on the chart.

Comparing growth, not size (Pro)

Show values as → Index: every line starts at 100 in the first visible period, so a small region that grew 30% is visibly ahead of a large one that grew 5%.

Events in one minute (Pro)

  1. Make a table Events with two columns: Date and Event.
  2. Relate Events[Date] to your calendar date (many-to-one, single direction).
  3. Drag Events[Event] to the Events field and set it to First.

Two events in the same period? Use a measure instead:

Event text = CONCATENATEX ( VALUES ( Events[Event] ), Events[Event], " · " )

Annotations work the same way: any text column set to First, or a text measure, in Annotations pins a note to the first measure's line.

Selection, zoom and interaction

  • Click a point to filter the rest of the page; with a Legend field, click a legend item to select the whole series. Ctrl/Cmd + click adds; click again or click the background to clear.
  • Highlight: when another visual filters this one, the highlighted values are drawn over a faded line.
  • Tooltip with a crosshair; report page tooltips are supported. At a period with an event, the tooltip shows its full text.
  • Zoom: Ctrl/Cmd + mouse wheel, or + and − with the chart focused; drag the optional zoom slider under the axis. Esc or Reset zoom goes back. The Y axis fits the zoomed range unless you turn that off.
  • Bookmarks restore the selection. Right-click opens the Power BI context menu. A hierarchy in Axis gives drilldown.
  • When the report author turns interactions off, clicks do not filter and zoom is off.

Accessibility

  • Keyboard: Tab into the visual; left and right arrows move along the axis, up and down between series; Home/End and PageUp/PageDown jump; Enter or Space selects; Esc clears (or resets the zoom); the context-menu key or Shift + F10 opens the menu. With small multiples, Shift + left/right moves between panels.
  • Each point is announced to screen readers with its series, date and value; the chart describes how many series and points it has.
  • High contrast: the visual uses the colours of the Windows contrast theme and tells series apart by line pattern and marker shape.
  • The layout adapts to the size of the visual: in small sizes labels, legend and axes give way, down to a sparkline.

Troubleshooting

My line drops to zero in an empty month

The line is drawn from your data: a zero is a real zero returned by the measure. Measures that wrap the result in + 0 or COALESCE(…, 0) turn a blank into zero; return BLANK() instead and the month is a gap. If you do want the line to go to zero, choose Lines → Missing values → Zero; Connect draws straight over the gap.

The axis shows categories, not a time axis

The time axis needs a single date column (Date data type) on Axis. A date hierarchy (Year, Quarter, Month) gives evenly spaced categories, like any category axis. In the field well, choose the date field itself instead of Date Hierarchy.

“Events expects text: set the field to First”

A text column in Events or Annotations is summarised as Count by default, so the visual receives numbers. In the field well, open the field menu and choose First. Or use a text measure.

Two events in the same period show only one

With First, Power BI sends one text per period. Use a measure that joins them: Event text = CONCATENATEX ( VALUES ( Events[Event] ), Events[Event], " · " ).

“Power BI sent only part of the data”

Power BI sends up to 30,000 combinations of axis, small multiples panel and legend value. Above that, the visual draws what arrived and says so. Filter the page, use a coarser axis (week instead of day) or fewer legend values.

“N values without a date on the axis”

Some rows have a blank date. They cannot be placed on a time axis, so they are left out and counted in the note. Check the relationship between your fact table and the calendar.

Gap shading or the variance label does not appear

Both need a Plan or a Prior year field: without a reference there is nothing to compare against. Gap shading is in Plan, prior year and forecast → Gap shading. It is not drawn at very small sizes (compact and sparkline layouts).

Zoom does nothing

Zoom uses Ctrl + mouse wheel (Cmd on a Mac) or the + and − keys with the chart focused. It is off in format mode, when Interactions → Zoom is off, or when the report author turned interactions off. Esc or the Reset zoom button goes back to the full range.

I see a “Pro preview” watermark

A Pro feature is turned on and you are editing without a licence. Turn it off to remove the watermark, or get a licence. Readers of the report without a licence see the free chart, with no watermark.

FAQ

Why does an empty month break the line?

Because a missing value is not a zero. A line that drops to zero in a month without data tells the meeting that sales collapsed, when the data was simply not there. If your measure returns 0 instead of BLANK(), the month is a real zero and is drawn as one; return BLANK() and it is a gap. By default the line stops and starts again; you can connect over the gap or draw zero in Lines → Missing values.

How does gap shading choose its colour?

The area between the actual line and the reference (Plan, or Prior year when there is no plan) is green where actual is above and red where it is below, split exactly at the point where the lines cross. For costs, where lower is better, swap the two colours in Plan, prior year and forecast. The Forecast field is never used for gap shading. Gap shading is not drawn at very small sizes, when the visual switches to its compact or sparkline layout.

What does “Split actual and plan” do?

When the plan or forecast has values after the last actual period, that part is drawn with a longer dash and a thin vertical line marks Actual | Plan. Turn it off in Plan, prior year and forecast.

How do I add events?
  1. Make a table Events with two columns: Date and Event.
  2. Relate Events[Date] to your calendar date.
  3. Drag Events[Event] to the Events field and set it to First.

Two events in the same period? Use a measure instead: Event text = CONCATENATEX ( VALUES ( Events[Event] ), Events[Event], " · " ). Events are part of Pro.

Is the trend line a forecast?

No. The linear trend is a least-squares line from the first to the last point of the series, and it is not extended. The moving average looks back N periods inside each stretch of the line, so it does not cross a gap. For a forecast, use your own measure in Forecast.

How many fields and rows can it use?

Axis, Legend and Small multiples take one field each; Values up to 6 measures; Secondary values up to 3; Plan, Prior year, Forecast, Target line, Events and Annotations one each. Power BI sends up to 30,000 combinations of axis, panel and legend value; when more exist, a note in the visual says the chart is incomplete. The limits are the same in the free version and in Pro.

Why does the target line disappear with Show values as?

With Show values as (Pro) set to index, % change or running total, the target line is not drawn: an absolute target has no index. Index and % change use the first visible period of each series as the base, so the base moves when you zoom. If that base value is 0, there is nothing to divide by and the series is left empty.

Does it use my number formats?

Yes: the number format of each measure from the model, dynamic format strings included, in the report's language. Show values as (Pro) uses its own format for index and %.

Does it follow my report theme?

Yes. Report theme is the default template: series colours and text come from your theme, like a native visual. Colours you set yourself always win.

Do bookmarks keep my selection?

Bookmarks keep the points you select and the filters of the page. Like every Power BI visual, they do not keep formatting.

What is the “Pro preview” watermark?

While you edit a report without a licence, Pro features you turn on are drawn working on your own data under a watermark that names them, and Power BI shows its licence notice. Reading view shows the free chart. With small multiples, the preview draws the first 4 panels and reading view without a licence shows the first panel. Where Power BI provides no licence information (for example when you are not signed in to Power BI Desktop), the free chart is shown.

How do I get Pro?

On the visual's Microsoft AppSource page, choose Buy now (not Install free). Licences are per user and managed by Microsoft; every person who should see the Pro features needs one. Restart Power BI Desktop after the licence is assigned. See tcviz.com/licensing.

Is my data sent anywhere?

No. The visual makes no network requests and stores nothing outside your report. The links on the start screen open only when you click them, through Power BI.

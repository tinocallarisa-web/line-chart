WHAT IT DOES
──────────────────────────────────────────
✅ A real date axis: an empty month is a gap, never a zero (or connect / zero, your choice)
✅ End labels with the last value, kept apart so they never overlap
✅ Plan, prior year and forecast as their own fields, with the gap to plan shaded green or red
✅ The plan carries on dashed after the last actual month, marked "Actual | Plan"
✅ Target line from a measure: flat, or stepped when the target changes by period
✅ Trend line (linear or moving average), peaks and lows, smooth lines that never overshoot the data
✅ Several measures, a legend and a secondary axis at the same time
✅ Zoom with Ctrl + wheel, sort categories, a source note under the chart
✅ Click to filter, highlight, drilldown, keyboard navigation, context menu and high contrast
✅ The measure's number format, dynamic format strings included; twelve languages
✅ No network requests: everything is computed inside your report

──────────────────────────────────────────
EVENTS IN ONE MINUTE
──────────────────────────────────────────
1. Make a table Events with two columns: Date and Event.
2. Relate Events[Date] to your calendar date.
3. Drag Events[Event] to the Events field and set it to "First".
Two events in the same month? Use a measure instead:
Event text = CONCATENATEX ( VALUES ( Events[Event] ), Events[Event], " · " )
